# aspen-gcc-optimizer-in-matlab

This project was made for a university assignment in the subject [Process Design II](https://www.chemeng.ntua.gr/the_course/Design_II)

The goal of the code is to open an aspen bkp file, run it and fetch the necessary information to produce the heat Grand Composite Curve.

Also, this project provides a way to optimize the variables of a process, by minimizing its' TAC.

In general, this is not a very variable codebase, because it was used specifically for the assigned project and should only be used as a refrence for similar projects.
See the scripts/aspen/ folder for an interface of how to interact with the Aspen Plus V11 ActiveX protocol in Matlab.
